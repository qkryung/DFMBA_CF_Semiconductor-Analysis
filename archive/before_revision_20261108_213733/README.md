## 파일

- `index.html` · `study.html`: 빌드 산출물. 외부 라이브러리와 인터넷 연결 없이 열립니다(출처 링크만 인터넷 필요).
- `content/deck.json`: 제목, 파트, 시간 배분, 숫자 검증표(40항목), 예상 질문, 용어 사전.
- `content/part0.json` ~ `part3.json`: 장표 본문과 학습 노트(해설 문단, 표, 발표 대본, 연결 문장, 예상 질문과 답, 출처).
- `data.json`: 출처 184개, WSTS 연간 매출, Gartner 순위 스냅샷(1990·2000·2010·2017·2020·2024·2025), 시대 구분, 린니어 FY2003–2016 시계열(10-K·XBRL).
- `theme.css` · `app.js` · `build.py`: 스타일, 발표 엔진, 빌드 스크립트.
- `archive/v1/`: 2026-11-04 1차 자료(32장 구성 `index.html`/`study.html`, `content.json`, 시대별 심화 해설, Word 인쇄본). 현재 발표에는 쓰지 않습니다.

## 발표 화면 조작

좌우 방향키 / Space 이동, `N` 발표자 메모, `S` 이 장표의 출처, `T` 목차, `F` 전체화면, `B` 화면 가림, `P` 발표자 창(별도 모니터). 상단에서 전체 경로와 15분 핵심 경로를 전환합니다. 아젠다 카드, 파트 구분 장표의 목록, 시대 지도의 띠를 누르면 해당 장표로 이동합니다.

## 숫자와 출처 원칙

- 조사 기준일 2026-11-05. 공부용 자료 부록의 숫자 검증표에 확인(1차 출처) / 2차(언론·연구기관 인용) / 계산(1차 자료로 직접 계산) / 미확인을 구분했습니다.
- 매출 순위는 Gartner 반도체 공급업체 매출 기준이며 파운드리(TSMC)·장비사는 제외됩니다. 확인된 대표 연도 스냅샷만 재생하고 사이 연도를 보간하지 않습니다. 시장 규모는 WSTS를 씁니다.
- 린니어 수치는 FY2003–2016 10-K·DEFM14A·SEC XBRL, ADI 수치는 10-K·8-K에서 확인했습니다. 2026년 하반기 상황(실적·금리·선거·시장)은 발표일까지 바뀔 수 있으므로 WSTS 가을 전망(12월 초), NVIDIA Q3 FY27(11/17), ADI Q4 FY26(11/24)은 발표 직전에 반영이 필요합니다.
- HBS 케이스 원문과 참고 이미지는 재배포하지 않습니다. 케이스는 출처를 밝힌 짧은 요약으로만 인용하고 도표는 새로 제작했습니다.
