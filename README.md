## 발표 구성 및 조작

1. 케이스 이후의 Linear Technology: 매출·배당·주주수익·경쟁사·인수 협상·11개 섹터 순위·기업 생애주기
2. 반도체 산업의 변천: 1947년부터 5개 시대, 4개 레이어 통합지도, 시대별 수요·거시환경·기업재무
3. AI 시대 마주한 재무적 이슈: 수요자 재무·금리·순환거래·규제·공급자 자본배분

좌우 방향키 / PageUp·PageDown으로 이동. T 목차, S 출처, F 전체화면, B 화면 가림. 선택창에 포커스가 있으면 방향키는 선택창에 적용됨. 통합지도의 항목을 누르면 요약 패널이 열림. 빅테크는 기업 선택과 원자료·산식 버튼을 제공함. 스터디는 검색, 모바일 목차, 글자 확대, 인쇄를 제공함.

## 데이터 범위

- 섹터 순위는 Fortune Global 500의 **확인 가능한 기업 내** 매출 상위 5개임. 1995·2000·2010·2020·2026 발표연도 스냅샷을 사용함. 매출 발생 회계연도와 발표연도는 다름.
- 1990년 동일 기준 자료는 미확보 상태로 명시함. 과거 공식 아카이브 일부 행 누락과 Global500 내 부동산 기업 부족을 임의 보충하지 않았음. 11개 섹터는 분석자 재분류이며 공식 GICS 역사 시계열 아님.
- 빅테크는 FY2021–25와 2026.09 TTM을 비교함. Microsoft 6월 결산, 나머지 12월 결산. TTM은 FY2025와 일부 중첩됨. FCF=영업CF−총현금 CAPEX, 금융리스 원금 제외. 부채비율=총부채/자본, 이자보상배율=영업이익/이자비용.
- 2026 산업 매출 두 배는 상반기 실제치 +102%임. 연간 +108%와 CAPEX·환원 규모는 해당 기관·회사 전망 또는 계획임.
- Linear 총주주수익 장표의 지수는 10-K 원본 그래프에서 판독한 반올림 근사치임. 배당 재투자를 포함하며 배당과 주가 상승의 인과관계를 주장하지 않음.

## 백업과 소스

수정 전 `index.html`, `study.html`, `build.py`, `app.js`, `theme.css`, `data.json`, `README.md`, `content/`는 `archive/before_revision_20261108_213733/`에 백업함. 기존 `archive/v1`도 유지함.

현재 생성 소스는 `build_v3.py`·`v3.js`·`v3.css`, 스터디 생성 소스는 `build_study_v3.py`임. 근거 데이터는 `data.json`, `research_financials.json`, `sector_history.json`, `macro_raw.json`, `boj_discount.csv`에 있음. 사진 저작자·라이선스는 `assets/v3/attribution.json`과 HTML 내부에 표기함. 이전 `content/`, `app.js`, `theme.css`는 새 빌드에 사용하지 않음.

node qa_v3.cjs               # jsdom 기반 기능검사 (TEMP/codex-html-qa 설치 필요)
