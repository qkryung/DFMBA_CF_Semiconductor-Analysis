좌우 방향키 / PageUp·PageDown / Space로 이동(이동 버튼은 화면 오른쪽 아래). T 목차, S 출처(근거 링크·산식·차트 데이터 표), F 전체화면, B 화면 가림. 장표 안의 출처 링크는 없앴고, 근거는 아래쪽 막대의 `출처` 버튼이나 S 키로 엶. 선택창에 포커스가 있으면 방향키는 선택창에 적용됨. 통합지도의 시대 구간을 누르면 요약 패널이 열리고, 위쪽 체크박스로 레이어를 켜고 끔. 섹터 순위는 왼쪽 목록에서 섹터를 고르거나 `산업 순환`으로 자동 전환하며, 기업 칸에 포인터를 올리면 그 기업의 순위 이동만 남김. 빅테크는 기업 선택을 제공함. 스터디는 검색, 모바일 목차, 글자 확대, 인쇄를 제공함.

**펜(그리기)**: D 또는 아래쪽 `펜` 버튼으로 켜고 끔. 색 4종, 선/형광펜 선택, Z 되돌리기, X 모두 지우기, Shift를 누른 채 그으면 직선, Esc 종료. 그린 선은 장표를 넘기면 지워지며 어디에도 저장하지 않음.

## 데이터 범위

- 섹터 순위는 **미국 Fortune 500** 기업의 섹터별 매출 상위 10개임. 1996·2001·2006·2011·2016·2021·2026년판을 쓰며, N년판은 직전 회계연도(N−1)의 매출 순위이므로 화면에는 **매출 연도 1995–2025(5년 간격 7개 시점)**로 표시함.
- 10개 섹터는 당시 Fortune 업종을 묶은 분석용 분류이며 공식 GICS 과거 시계열이 아님. 부동산은 Fortune 500 편입 기업이 적어 Top 10을 만들 수 없어 제외함. 합병은 존속 법인(인수 주체), 분할은 본업과 사명을 이어 간 쪽을 같은 기업으로 연결함. 분류·연결 규칙과 예외는 `build_sector_us.py`와 `sector_us.json`에 기록함.
- Fortune 아카이브 페이지에서 빠진 순위 29건은 공개 데이터셋 cmusam/fortune500(GitHub)의 값으로 채웠고(이 가운데 6건이 섹터 Top 10에 들어감), 값이 어긋난 2001년판 4건을 바로잡았음. 채운 값은 화면 툴팁에 표시함. Fortune 500은 미국 법인만 포함하고 다른 상장사의 자회사·비공개 기업은 빠지며, 2006년판에는 결산이 늦은 Fannie Mae·Freddie Mac이 없고, 2000년 유틸리티 매출은 에너지 트레이딩 총액 계상으로 부풀려져 있음.
- 섹터별 '1위 교체' 횟수는 7개 시점 사이에 매출 1위 기업이 바뀐 횟수임. 필수소비재(Walmart)·에너지(Exxon Mobil)는 0회, IT는 2회(IBM → HP → Apple)이며, 헬스케어(4회)와 유틸리티·커뮤니케이션·금융(각 3회)은 IT보다 많음. 에너지는 1위는 그대로지만 Top 10 구성은 크게 바뀌었음(1995년 Top 10 중 2025년에도 Top 10인 곳은 3곳).
- 빅테크 대시보드는 **역년 분기 2023Q1–2026Q3**(15개 분기)의 여덟 지표임. SEC XBRL(companyfacts)에 태그된 값만 쓰며 추정·보간하지 않음(`research_quarterly_fin.json`). 손익·현금흐름은 3개월 공시값을 우선 쓰고 없으면 회계연도 누계의 차감으로 구함. 매출 성장률=전년 동기 대비, FCF=영업CF−현금 CAPEX(금융리스 원금 미차감), 이자보상배율=분기 영업이익/영업외 이자비용, 부채비율=총부채/자본(분기 말). Meta의 분기 이자비용은 차입금 이자(금융리스 이자 제외) 기준이고 2024Q1·Q2는 분기별 값이 태그되지 않아 비워 둠. Microsoft는 6월 결산이어서 회계 분기를 역년 분기에 대응시킴.
- 빅테크 4사 FCF·Meta 차입 차트(① 투자 경쟁)는 FY2021–25와 2026.09 TTM을 비교함. TTM은 FY2025와 일부 중첩됨.
- 분기 차트(제4기, 2026 시장, 공급자 영업이익)는 SEC XBRL 분기 현금흐름, 삼성전자·SK hynix 분기 실적 발표, WSTS 월별 통계표를 사용하며 `research_quarterly.json`에 기록함. Microsoft는 회계 분기를 역년 분기에 대응시킴.
- 2026 산업 매출: WSTS 통계표(8월판)의 월별 실적을 합산하면 상반기 $722.0bn, 전년동기 대비 +108%임. 8월 6일 보도자료의 첫 집계($702bn·+102%)와는 집계 시점이 달라 차이가 있음. 3분기는 SIA 발표치로 앞 분기와 이어서 계산하지 않음. 연간 전망과 CAPEX·환원 규모는 해당 기관·회사의 전망 또는 계획임.
- Linear 인수 협상(DEFM14A)의 가치 범위는 Linear 측 재무자문사의 분석임. 'DCF 중간값 $59.25'는 범위 양끝의 산술 중간값으로 발표 자료에서 계산한 값임.
- 냉전기 군사비는 Correlates of War NMC v6.0의 명목 달러 값임. 소련 값은 루블 지출의 환산 추정치여서 출처마다 크게 다르므로 수준이 아닌 추세만 읽음.
- 1980년대 금리와 엔/달러는 월평균, 물가상승률은 CPI-U 전년동월비임(연방기금 실효금리 정점 19.1%는 1981.06 월평균). 달러지수 +54%는 1980.09 → 1985.03 구간이며, 달러는 플라자 합의(1985.09) 이전에 이미 정점을 지났음.
- 개념도(생애주기, 자산·부채의 시간, 순환 구조 등)는 설명용 그림이며 실제 수치가 아님.

## 백업과 소스

수정 전 `index.html`, `study.html`, `build.py`, `app.js`, `theme.css`, `data.json`, `README.md`, `content/`는 `archive/before_revision_20261108_213733/`에 백업함. 기존 `archive/v1`도 유지함.

현재 생성 소스는 `build_v3.py`·`v3.js`·`v3.css`, 스터디 생성 소스는 `build_study_v3.py`임. 근거 데이터는 `data.json`, `research_financials.json`, `research_quarterly.json`(분기 실적), `research_quarterly_fin.json`(빅테크 분기 손익·재무상태), `research_history.json`(냉전 군사비·1980년대 거시·Linear 인수 협상), `sector_us.json`(섹터 Top 10 · `build_sector_us.py`가 `research/fortune*_next.json`과 `research/fortune500_gap_rows.json`으로 생성), `macro_raw.json`, `boj_discount.csv`에 있음. 이전 섹터 자료 `sector_history.json`·`build_sector_history.py`는 남겨 두었으나 발표 자료 빌드에는 쓰지 않음. 사진 저작자·라이선스는 발표 자료용 `assets/v3/deck/attribution.json`, 스터디용 `assets/v3/attribution.json`과 HTML 내부에 표기함. 이전 `content/`, `app.js`, `theme.css`는 새 빌드에 사용하지 않음.

```
python build_v3.py           # 발표 자료만 재생성 (기업재무_발표자료_12조.html · index.html · v3_deck_content.json)
python build_sector_us.py    # 섹터 Top 10 자료(sector_us.json) 재생성
python build.py              # 두 문서 및 호환 진입파일 재생성
python build.py --study-only # 스터디만 재생성
python build.py --check      # 산출물·ID 기본 확인
node qa_v3.cjs               # jsdom 기반 기능검사 (TEMP/codex-html-qa 설치 필요)
```

## 검증 범위
